# Course material map

Pemetaan ini dibuat dari nama dan isi notebook yang ditemukan dalam `DM.zip`. Ini bukan klaim bahwa arsip tersebut memuat seluruh kursus.

## Reading Data
Notebook `01a_DEMO_Reading_Data.ipynb` memperlihatkan koneksi ke SQLite dan membaca hasil query ke Pandas DataFrame. Notebook `01b_LAB_Reading_Data.ipynb` berisi latihan membaca data dari `baseball.db`.

## Exploratory Data Analysis
Notebook `01c_LAB_EDA.ipynb` menggunakan `iris_data.csv`. Latihan mencakup pemeriksaan jumlah baris/kolom, tipe data, pembersihan nama spesies, statistik deskriptif per spesies, scatter plot, histogram, boxplot, dan pairplot.

## Feature Engineering
Notebook `01d_DEMO_Feature_Engineering.ipynb` menggunakan Ames Housing Data. Isi yang terlihat mencakup penanganan kategori dengan one-hot encoding, transformasi log pada fitur yang skewed, pemeriksaan missing values, eksplorasi hubungan fitur-target, dan contoh fitur polinomial/interaksi. Dataset tambahan tersedia di subfolder `data/`.

## Hypothesis Testing
Notebook `01e_DEMO_Hypothesis_Testing.ipynb` menggunakan contoh prediksi lemparan koin dan distribusi binomial untuk menjelaskan cutoff, confidence/error trade-offs, Type I/Type II errors, dan pengaruh ukuran sampel.

## Batas cakupan
Arsip ini tidak berisi notebook terpisah yang secara eksplisit bernama Data Cleaning atau Final Project. Jangan menyatakan bahwa bagian tersebut sudah lengkap hanya berdasarkan arsip ini. Jika kursus menyediakan materi lain, tambahkan setelah diperiksa.
