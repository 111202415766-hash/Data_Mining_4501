# Workflow belajar yang disarankan

1. Baca tujuan pembelajaran di awal notebook.
2. Jalankan notebook dari atas ke bawah dan pastikan file dataset ditemukan.
3. Untuk setiap visualisasi atau tabel, tulis 1–3 kalimat interpretasi sendiri.
4. Untuk lab, coba jawab pertanyaan sebelum melihat bagian solusi yang tersedia di notebook.
5. Catat error, penyebab, dan perubahan yang dilakukan.
6. Jangan menghapus bagian asli dari materi kursus. Jika membuat versi yang diperbaiki, simpan sebagai notebook terpisah dan jelaskan perubahan.
7. Jangan mengklaim seluruh kursus selesai jika baru beberapa notebook yang tersedia.
